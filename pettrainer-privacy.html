PetTrainer 개인정보처리방침

시행일: 2026-10-26 · 운영자: Herion / Baronsys · 문의: moonstar@baronsys.com

처리하는 자료

반려동물 프로필, 보호자가 입력한 훈련·돌봄 기록, 메모와 선택적으로 녹음한 음성 신호는 기기에 저장합니다. 개발자 서버에 전송하지 않습니다. 회원가입·광고·분석 SDK가 없습니다.

권한

마이크는 사용자가 음성 신호 녹음을 시작할 때 사용합니다. 훈련 소리와 타이머는 행동을 진단하거나 치료하는 기능이 아닙니다.

백업

사용자가 JSON 백업을 내보내고 복원할 수 있습니다. 녹음 음성 파일은 JSON 백업에 포함되지 않습니다. 운영체제 백업 설정에 따라 기기 데이터가 백업될 수 있습니다. 직접 선택한 저장소의 정책도 확인하세요.

보관과 삭제

앱 내 기록·프로필 삭제 또는 Android 앱 저장공간 삭제로 기기 자료를 삭제할 수 있습니다. 외부로 내보낸 백업은 별도로 삭제하세요.

외부 서비스와 문의

사용자가 이메일 문의로 제공한 정보는 문의 처리에 사용됩니다. 외부 서비스 이용에는 해당 제공자의 정책이 적용됩니다. Google 개인정보처리방침. 자료 처리 방식이 변경되면 이 페이지의 시행일을 갱신합니다.
