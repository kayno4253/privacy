시행일: 2026-10-26 · 운영자: Herion / Baronsys · 문의: moonstar@baronsys.com

오디오

사용자가 보내기를 시작하면 시스템 재생 오디오를 선택한 수신 기기로 전송합니다. Android가 요구하는 녹음 및 화면 공유 권한을 사용할 수 있지만 이 앱은 화면 영상이나 마이크 입력을 녹화하는 기능을 제공하지 않습니다. Firebase에는 오디오를 저장하지 않습니다.

연결 정보와 Firebase

연결 코드 기능은 Firebase 익명 인증과 싱가포르 Realtime Database를 사용합니다. 익명 UID, 기기 이름, IP 주소가 포함될 수 있는 SDP와 연결 시각을 처리합니다. 인증 토큰은 앱 프로세스 메모리에 보관합니다. 방 목록 조회는 차단하며 방 소유자와 해당 접속 요청자에게 권한을 제한합니다.

보관

앱은 연결 처리 후 SDP 삭제와 받기 종료 시 방 삭제를 시도합니다. 강제 종료나 네트워크 실패 시 자료가 남을 수 있으며 자동 정리 작업은 아직 제공되지 않습니다. 앱 종료만으로 Firebase 익명 계정이 삭제되지는 않습니다. 삭제 문의 시 연결 코드와 대략적 이용 시각을 알려주세요. 인증 토큰이나 비밀번호는 보내지 마세요.

전송과 중계

WebRTC는 암호화된 전송을 사용합니다. LAN WebSocket과 기본 중계 방식은 별도의 전송 암호화를 제공하지 않으므로 신뢰하는 사설 네트워크에서 사용하세요. 사용자가 TURN 또는 중계 서버를 설정하면 해당 서버를 거쳐 오디오가 전달됩니다. STUN 서버는 직접 연결 경로 확인에 이용됩니다.

기기 저장과 삭제

기기 이름과 연결 설정은 기기에 저장합니다. 앱 데이터 삭제로 기기 설정을 삭제할 수 있습니다. 사용자 지정 중계 서버의 보관 방식은 해당 운영자에게 확인하세요. 광고·분석 SDK는 포함하지 않습니다.

외부 서비스와 문의

사용자가 이메일 문의로 제공한 정보는 문의 처리에 사용됩니다. 외부 서비스 이용에는 해당 제공자의 정책이 적용됩니다. Google 개인정보처리방침. 자료 처리 방식이 변경되면 이 페이지의 시행일을 갱신합니다.
