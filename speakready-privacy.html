시행일: 2026-10-26 · 운영자: Herion / Baronsys · 문의: moonstar@baronsys.com

처리하는 자료

발표 대본, 이미지, 연습 기록, 사용자가 선택적으로 녹음한 음성은 기기에 저장됩니다. 개발자 서버로 업로드하지 않습니다. 로그인·광고·분석 SDK는 포함하지 않습니다.

마이크와 음성

사용자가 녹음 또는 기기 음성 인식을 선택하면 마이크를 사용합니다. 지원 기기의 온디바이스 음성 인식과 오프라인 TTS를 사용하며, 지원되지 않으면 안내합니다. 발표 내용을 자동으로 외부 AI에 전송하지 않습니다.

백업과 인쇄

사용자가 백업·복원·인쇄/PDF를 선택한 경우 운영체제 문서 선택기 또는 인쇄 서비스로 자료를 전달합니다. 클라우드 저장소나 프린터를 선택하면 해당 서비스의 정책이 적용됩니다. 백업에는 발표와 녹음이 포함될 수 있습니다.

보관과 삭제

발표와 연습 기록은 직접 삭제하거나 Android 앱 저장공간을 삭제하여 제거할 수 있습니다. 내보낸 파일은 사용자가 저장한 위치에서 별도로 삭제해야 합니다. 앱 삭제 전 필요한 자료를 백업하세요.

외부 서비스와 문의

사용자가 이메일 문의로 제공한 정보는 문의 처리에 사용됩니다. 외부 서비스 이용에는 해당 제공자의 정책이 적용됩니다. Google 개인정보처리방침. 자료 처리 방식이 변경되면 이 페이지의 시행일을 갱신합니다.
