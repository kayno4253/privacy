1. 기기 안에서 처리하는 정보

기본 어종 인식은 기기에 설치한 모델로 사진을 처리합니다. 조과 기록, 선택한 사진, 위치, 즐겨찾기, 설정과 날씨 캐시는 기기에 저장됩니다. 운영자는 광고 또는 분석 SDK를 사용하지 않으며 연락처, 통화 기록, 문자 또는 광고 식별자를 수집하지 않습니다. 이번 비공개 테스트 버전의 온라인 커뮤니티와 Firebase 서버 동기화는 설정되어 있지 않습니다.

2. 외부 서비스와 통신

  • 날씨: MET Norway(api.met.no)에 선택한 지점 또는 현재 위치의 좌표를 소수 둘째 자리로 반올림해 전송합니다. 앱 식별 문자열과 접속 IP가 전달될 수 있습니다.
  • 지도: OpenFreeMap(tiles.openfreemap.org)에 표시 구역의 지도 자료를 요청합니다. 접속 IP와 요청 구역은 제공자의 접속 기록에 남을 수 있습니다.
  • 인식 모델: Google Play 자산 전송으로 모델을 설치합니다. Google의 서비스 정책이 적용됩니다.
  • 선택적 서버 인식: 사용자가 설정에서 본인의 Fishial.AI API 자격증명을 등록하고 기기 내 모델이 준비되지 않은 상태에서 인식을 실행하면 선택한 사진을 Fishial.AI 서버로 전송합니다. 기본값은 이 기능을 사용하지 않습니다. 자격증명은 기기에 저장되며 설정에서 제거할 수 있습니다. 사진의 서버 처리·보관에는 Fishial.AI의 정책이 적용됩니다.
  • 외부 링크: 사용자가 사진 검색, 위키백과 또는 길찾기를 누르면 종 이름이나 선택한 목적지가 Google, Wikipedia, Kakao 등 선택한 서비스로 전달됩니다. 해당 서비스의 정책이 적용됩니다.

앱의 외부 서비스 요청은 HTTPS를 사용합니다. 운영자는 위 제공자의 접속 기록에 접근하지 않습니다. 외부 제공자는 각자의 정책에 따라 데이터를 처리하므로, 기기에서만 처리되는 정보와 외부 요청 정보를 구분해 주세요.

3. 선택 권한

위치 권한은 날씨, 지도와 조과 위치 기록에 사용하며, 거절해도 지점을 직접 선택할 수 있습니다. 카메라·사진은 사용자가 촬영하거나 선택한 이미지에 사용합니다. 알림은 사용자가 설정한 금어기·물때 안내를 기기에서 예약합니다. 권한은 기기 설정에서 변경할 수 있습니다. 백그라운드 위치 추적은 하지 않습니다.

4. 보관, 공유 및 삭제

기기 기록은 앱에서 삭제하거나 앱 데이터 삭제로 제거할 수 있습니다. 앱 제거 시 앱 전용 데이터가 삭제되지만 사용자가 내보낸 백업, 공유한 사진과 운영체제 백업은 별도로 남을 수 있습니다. 내보내기·공유는 사용자가 선택한 대상에만 실행됩니다. 외부 서비스 기록의 보관·삭제는 각 제공자의 정책을 따릅니다. 개인정보 문의·열람·정정·삭제 요청은 kayno@naver.com으로 보내 주세요. 운영자가 보유하지 않은 외부 서비스 데이터는 해당 제공자에 문의해야 할 수 있습니다.

5. 아동 및 변경

본 앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 정책 변경 시 이 페이지의 시행일을 갱신합니다.

FishVision Privacy Policy

Effective: 23 October 2026. Operator: Herion. Contact: kayno@naver.com. Applies to com.fishingapp.fishing_app, closed-test version 2.3.0.

On-device processing

Default fish identification processes selected photos with an on-device model. Catch logs, photos, optional locations, favorites, settings and weather caches stay on the device. No advertising or analytics SDK is used. Online community/Firebase synchronization is not configured in this test build.

External requests

Weather requests send coordinates rounded to two decimals, app identification and the connection IP to MET Norway. Map requests send the displayed area and connection IP to OpenFreeMap. Google Play delivers the recognition model. These providers may keep their own access logs; the operator cannot access those logs.

Optional Fishial.AI recognition is used only if you supply your own API credentials and run recognition without a ready on-device model. Selected photos then go to Fishial.AI over HTTPS, subject to that provider's processing and retention policy. Credentials are stored locally and can be cleared in Settings. External image searches, Wikipedia and directions open only on request and may send the species name or selected destination to the chosen provider. App network requests use HTTPS.

Permissions and control

Location is optional for weather, map positioning and catch records; you can select a spot manually. Camera/photos process images you choose. Optional reminders are scheduled locally. There is no background location tracking. You can revoke permissions in device settings.

Retention and deletion

Delete local records in the app or clear app data. Uninstalling removes app-private data, but exported files, shared copies and operating-system backups may remain under your control. Sharing and backup export occur only when you choose a destination. Third-party retention/deletion follows the provider's policy. Contact kayno@naver.com for privacy, access, correction or deletion requests; data held only by an external provider may require contacting that provider.

The app is not directed at children under 14. Policy changes will be reflected by the effective date on this page.
